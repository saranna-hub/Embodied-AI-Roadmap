# 具身智能学习路线

## 1. 基础与工具
学习 Python、PyTorch、线性代数、刚体变换与 Git，完成最小训练和评估实验。

## 2. 感知与表征
学习相机模型、深度估计、分割、位姿估计与多模态表征，理解坐标系、时间同步和误差来源。

## 3. 数据采集与治理
理解遥操作、UMI、EGO 和手套数据，建立采集、同步、质检、标注、格式转换与版本管理流程。

## 4. 策略学习
从行为克隆开始，学习 ACT、扩散策略、流匹配与视觉语言动作模型，区分训练损失和真实任务成功率。

## 5. 仿真与实机闭环
建立可重复任务、成功标准、失败分类与回归测试，完成采集、训练、部署、评估和补采闭环。

## 论文阅读模板
- 解决什么问题，前提是什么？
- 输入、输出、模型结构和训练目标是什么？
- 使用哪些数据集与评测指标？
- 相比基线的收益与限制是什么？
- 是否开源，复现需要哪些资源？

每日论文更新功能尚未启用。
