# 学习路线（初稿）

这不是完整课程。先给出学习顺序及每阶段要做的练习，后续每个主题会补可运行代码与参考资料。

| 阶段 | 学什么 | 完成标准 |
| --- | --- | --- |
| 1. 机器人基础 | 坐标变换、正逆运动学、常见控制接口 | 写出 SE(3) 变换程序，并在仿真中控制末端到指定位置 |
| 2. 模仿学习 | 行为克隆、ACT、Diffusion Policy | 用公开演示数据训练策略，记录成功率与失败案例 |
| 3. VLA 与世界模型 | 视觉语言特征、动作表示、训练流程 | 跑通一个开源模型的推理，解释输入输出和动作坐标系 |
| 4. 人类示范数据 | EGO、UMI、手套、VIO、手部姿态、动作对齐 | 从一段示范中得到时间对齐的图像与动作序列 |
| 5. 系统集成 | MuJoCo、运动规划、双臂协作、失败恢复 | 在仿真中完成抓取—搬运—放置的连续任务 |

学习顺序可以按背景调整。了解深度学习的读者可以从第 2 阶段开始；有机器人经验的读者可以直接做第 4、5 阶段。
