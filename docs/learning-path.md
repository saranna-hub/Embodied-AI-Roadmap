# 具身智能学习路线

## 阶段 1：基础
机器人运动学、坐标系、深度学习、Transformer。实践：实现 SE(3) 变换与简单机械臂正逆运动学。

## 阶段 2：机器人学习
行为克隆、ACT、Diffusion Policy、强化学习。实践：在 MuJoCo 里训练一个抓取任务。

## 阶段 3：基础模型
VLM、VLA、World Models、动作表示和模型训练。实践：阅读一份开源 VLA 训练配置并运行推理。

## 阶段 4：数据与 Human-to-Robot
EGO、UMI、手套、SLAM/VIO、手部姿态、Retarget、跨本体对齐。实践：完成多模态同步和数据质量检查。

## 阶段 5：系统闭环
行为树、运动规划、双臂协调、接触控制、Sim2Real。实践：移动双臂取件—搬运—装配—确认。

每阶段后续补充：知识地图、必读资料、开源代码、可复现教程、验收题目。
