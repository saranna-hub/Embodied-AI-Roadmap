# 轮式双臂：从取放到接插件装配

这是一个待验证的实践计划，**不是已经完成的项目或实验结果**。

## 第一个演示：跨工位取放

移动平台到取料位，识别零件并抓取，再移动到放料位完成定位放置。先用固定工位和已知物体搭建基线，记录任务成功率、耗时、定位误差、失败原因。底盘导航与机械臂动作采用分层控制，避免直接让一个模型负责全部安全动作。

## 第二个演示：双臂协作插接

一只手固定工件，另一只手对准并插入接插件。把过程拆成抓取、对准、接触、插入、到位检查、失败恢复。用腕部视觉判断相对位置，用机器人端力/触觉判断接触。人类数据手套用于提供抓握和接触阶段参考，不直接当作机器人力控真值。

## 要采什么

- 头部与腕部视频；标定参数及统一时间戳。
- 人类手部关节、触觉信号、任务阶段及成功/失败标签。
- 机器人末端位姿、关节、夹爪状态和传感器反馈。

## 怎么评估

至少比较三组：仅机器人示范、机器人示范加人类视觉数据、再加入手套派生的接触阶段标签。固定测试场景与随机种子，报告试验次数和每项任务成功率。只有在一致的评测条件下，才能判断手套数据是否真正带来收益。
