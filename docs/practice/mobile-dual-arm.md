# 工业轮式双臂实践路线

目标：通过 EGO/UMI/数据手套的人类示范与少量机器人数据，在轮式双臂上实现可复现的工业操作闭环。

1. **基线**：移动到工位、双臂抓取、定位放置、视觉验收。
2. **进阶**：双臂协作接插件插接，结合触觉识别接触阶段。
3. **数据**：头部/腕部 RGB、手套关节/触觉、机器人末端状态与力矩，保留时间戳与标定版本。
4. **方法**：传统控制负责安全和底盘；局部模仿学习策略负责对准、插入；行为树负责失败恢复。
5. **验证**：分别评估纯视觉、视觉+手套标签、视觉+机器人触觉反馈的成功率与泛化。

注意：人类手套压力不等于机器人末端真实力，不能直接当作机器人力控真值。
