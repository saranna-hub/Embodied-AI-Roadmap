# Embodied AI Roadmap

具身智能学习手册，中文为主。

这个仓库整理机器人学习需要的基础知识、论文、工具和实验。重点不是收集尽可能多的链接，而是回答三个问题：从哪里开始学？一项方法解决了什么问题？怎样用代码或实验验证？

**当前状态：网站框架已提交，课程和复现内容仍在建设。** [网站入口](https://saranna-hub.github.io/Embodied-AI-Roadmap/)（需启用 GitHub Pages）。

## 内容分类

- **具身基础模型**：模仿学习、强化学习、VLA、世界模型。
- **具身数据工程**：EGO、UMI、手套、采集、清洗和训练格式。
- **感知与重建**：SLAM/VIO、深度、手部姿态、手物交互。
- **Human-to-Robot**：动作转换、跨本体表征和任务迁移。
- **控制与执行**：运动规划、双臂协调、力控和任务编排。
- **仿真与评测**：MuJoCo、Isaac Sim、基准测试与真机验证。

分类决定文章存放位置，场景和难度作为标签；不会把同一篇论文复制到多个目录。

## 更新方式

研究记录只收录有来源、值得进一步查看的工作。引用实验数值时注明条件；厂商参数不当成独立测量结果。代码、权重、数据是否开放分别检查。

目前 GitHub Pages 部署工作流已提交；**自动检索及每日自动发文尚未启用**。仓库里不存在已经验证的每日无人值守发布系统。
