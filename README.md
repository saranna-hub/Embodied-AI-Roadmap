## 📰 每日 Research Radar
每天最多 2 项高价值新进展。默认 350 字以内，保留**原始来源、核心创新、落地价值、优先级、代码/数据状态、证据等级**。不凑数、不重复。深度分析在知识库里单独更新。

## ✅ 证据标准
- **论文结果**：仅代表作者报告；不等同于第三方复现。
- **厂商参数**：标记为官方声明；不等同于独立实测。
- **代码/数据开源**：分别核验可访问链接与实际内容。
- 不确认的技术指标不写为事实；公开资料不能包含公司私有信息。
- 欢迎通过 Issue / PR 纠错、补充开源项目和复现实验。
