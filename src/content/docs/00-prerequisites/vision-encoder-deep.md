# 让 RGB 变成 VLA 可使用的特征

## 1. 为什么不能直接把像素当作语言 Token？

图像有空间连续结构：颜色、纹理、局部边缘和物体之间的关系。视觉编码器提取可被下游 Transformer 读取的特征。像素值和语义特征并非同一种空间。

## 2. CNN 卷积如何工作？

一个 3×3 卷积核在图像局部窗口滑动，每个位置做加权求和。同一组参数在不同空间位置复用，这叫权重共享。CNN 天然具有局部归纳偏置；随着层数加深，感受野扩大。

## 3. ViT 的 Patch Embedding

224×224 RGB，使用 16×16 的非重叠 Patch，共 196 个 patch。单个 patch 16×16×3=768 维，线性投影到 d=768：

$$
z_i=W_px_i+b_p.
$$

全部 patch 得 [B,196,768]。实际模型还可包含特殊 Token、位置编码、不同分辨率策略，不应以 196 作为固定公式。

## 4. 为什么 SigLIP / CLIP 学到图文关联？

图文预训练通过配对数据约束图像特征和文本特征的匹配分数。CLIP 常通过 Batch 内 softmax 对比学习，SigLIP 使用成对 sigmoid 目标。二者都不是像素级目标检测器，想让机器人得到物体位置通常还要利用空间 Token、检测头或者后续任务模型。

## 5. 蒸馏为什么要对齐维度？

学生 PV feature 可能是 [B,30,17,256]，教师 feature 是 [B,60,34,1024]。必须定义空间对应关系和可学习/非学习的特征投影；简单 reshape 不能保证 Token 几何位置一致。

例子：先把教师空间插值到 30×17，再用投影头统一通道数，归一化后计算余弦或均方特征损失。若有多个教师，需要检查梯度方向和下游任务是否出现冲突。

## 6. 为什么 Feature 好不代表控制一定好？

图像教师可能擅长通用分类、深度、语义，但机器人抓取还依赖接触、遮挡、动作误差和控制时延。离线蒸馏 loss 下降必须与闭环任务结果分开评估。

## 7. 最小 Patchify 代码

~~~python
import torch
from torch import nn
x=torch.randn(2,3,224,224)
embed=nn.Conv2d(3,128,kernel_size=16,stride=16)
f=embed(x)                               # [2,128,14,14]
tokens=f.flatten(2).transpose(1,2)      # [2,196,128]
print(tokens.shape)
~~~

**思考**：为什么不能把教师的 [60,34] 和学生 [30,17] 直接逐元素相减？因为空间位置数量不同，且没有定义合理对应关系。
