# 从矩阵乘法开始，算到 Attention

本课不假设你学过机器学习。先用机器人观测例子理解向量、矩阵、概率、归一化，再推导 QKV。

## 1. 一个数、一个向量、一批图像

单个关节角是标量，三个空间位置值是向量，一幅 RGB 图片通常形状为 [3,H,W]。如果采集 B 个时刻、N 路相机，形状可写成 [B,N,3,H,W]。

### 向量维度不等于物理轴数

末端坐标 [x,y,z] 的三个维度有明确物理含义，但 Transformer 隐藏向量的 1024 维并不意味着 1024 个物理自由度。它们是训练中学习到的特征坐标。

## 2. 点积到底计算了什么？

$$
s=q^\top k=\sum_{i=1}^{d}q_i k_i.
$$

取 q=[1,2]，k=[3,4]，点积为 1×3+2×4=11。点积越大不一定越相似，因为向量模长也影响得分。余弦相似度先除去模长：

$$
\cos\theta=\frac{q^\top k}{\|q\|\|k\|}.
$$

Attention 使用可学习的 Q/K 投影和缩放点积，**不是直接进行余弦相似度**。

## 3. 矩阵乘法逐格计算

设三个 Token 组成：

$$
X=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}
$$

形状 [3,2]。选用权重：

$$
W=\begin{bmatrix}2&1\\1&3\end{bmatrix}
$$

则 $Y=XW$，第一行 [2,1]，第二行 [1,3]，第三行 [3,4]。输出仍是三个 Token，每个 Token 从二维映射成二维。换成 W=[2,4] 形状就会映射为 4 维。

## 4. 为什么要 Softmax？

如果某个 Query 对三个 Key 的得分为 [2,1,0]，分别取指数，得到 [7.389,2.718,1]，再除以三者之和 11.107，得 [0.665,0.245,0.090]。

$$
p_i=\frac{\exp(s_i)}{\sum_j\exp(s_j)}.
$$

每个权重非负且总和为 1。实际实现为数值稳定，通常先减去最大值：softmax([2,1,0])=softmax([0,-1,-2])。这利用指数函数的平移不变性。

## 5. 为什么“均值回归”会出问题？

同一个物体可以左手抓或右手抓。动作候选 [-1,+1] 各占一半，普通平方误差下的最优常数预测是均值 0，但在障碍物正中央，0 可能完全不可执行。**概率分布建模**可以保留多种动作模式，这也是学习扩散/Flow Matching 的数学动机之一。

## 6. 从数学直接走向代码

~~~python
import torch
x = torch.tensor([[1.,0.],[0.,1.],[1.,1.]])
w = torch.tensor([[2.,1.],[1.,3.]])
print(x @ w)                  # [[2,1],[1,3],[3,4]]
scores = torch.tensor([2.,1.,0.])
print(torch.softmax(scores,dim=0))
~~~

### 自测与答案

Q 是 [B,5,64]、K 是 [B,12,64]，Q×Kᵀ 是什么形状？答：[B,5,12]。这代表 5 个查询与 12 个 Key 的两两匹配，不是模型总参数量。
