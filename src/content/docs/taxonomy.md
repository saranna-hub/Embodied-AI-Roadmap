本项目只有六个一级技术领域。论文“系列”属于模型家族内部的阅读关系，**不另设一级分类**。

| 一级领域 | 核心研究问题 | 典型子主题 |
| --- | --- | --- |
| 01 具身基础模型 | 策略如何从观察生成动作？ | BC、RL、VLA、World Models |
| 02 具身数据工程 | 怎么采集和处理可用于训练的数据？ | EGO、UMI、手套、时钟同步、格式 |
| 03 感知与重建 | 视觉怎样恢复世界的三维状态？ | SLAM/VIO、深度、Hand Pose、HOI |
| 04 Human-to-Robot | 人类示范怎样迁移到机器人？ | Retarget、动作对齐、Robotization |
| 05 控制与执行 | 策略怎样在真实机器人上安全执行？ | 运动规划、力控、双臂协调 |
| 06 仿真与评测 | 怎样建立可比较的实验？ | MuJoCo、Isaac Sim、Sim2Real |

### 系列与专题的区别

π₀ → π₀.₅ 等具有同一研究线的延续性，适合写**论文家族**；Ego2Robot 与 UMI-Bridge 研究相似问题但来自不同工作，适合写**技术专题**。一篇论文只维护一份正文，其他页面用链接关联。
